Privacy Policy

Terakhir diperbarui: 2026

Kebijakan ini menjelaskan bagaimana Auto Video Poster ("Aplikasi") menangani data.

1. Data yang Digunakan

Aplikasi hanya menggunakan token otorisasi (OAuth) TikTok milik pengguna untuk mengunggah video atas nama pengguna. Aplikasi tidak mengumpulkan, menjual, atau membagikan data pribadi kepada pihak ketiga.

2. Penyimpanan

Token akses dan refresh disimpan secara lokal di server pribadi pengguna, hanya untuk keperluan pengunggahan. Token dapat dihapus kapan saja oleh pengguna.

3. Penggunaan Data TikTok

Aplikasi mengakses API TikTok hanya untuk mengunggah konten (Content Posting API). Aplikasi tidak membaca, menyimpan, atau menganalisis data pengguna TikTok lain.

4. Pencabutan Izin

Pengguna dapat mencabut akses aplikasi kapan saja melalui pengaturan keamanan akun TikTok.

5. Kontak

Pertanyaan mengenai privasi dapat dikirim ke pemilik aplikasi.
